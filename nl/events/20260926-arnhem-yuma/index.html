Wat ga je doen?

CodeCombat

Programmeer je held

Je speelt een spel. Je held doet alleen wat jij in code opschrijft. Zo leer je programmeren terwijl je speelt.

Meer over deze module
Sonic Pi

Maak muziek met code

Je schrijft code in Ruby en je computer speelt het af als muziek. Jij bepaalt de beat.

Meer over deze module
mBot2

Laat je robot rijden

Je leert hoe een robot werkt. Je programmeert je eigen mBot2. Hij rijdt, reageert en voert jouw opdrachten uit.
